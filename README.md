# APIClient v5.0



> 开源多模型API客户端，支持多模型切换、联网搜索、文本过滤、Agent本地沙箱办公、AI视觉截图，基于Tkinter纯GUI实现。

## 📋 项目介绍
APIClient 是面向开发者的通用大模型API桌面客户端。
兼容各类 OpenAI 协议大模型接口（DeepSeek、豆包、通义千问等），内置联网搜索附属API、挡位式文本过滤；v5.0 新增 Agent 本地办公沙箱与「AI眼睛」截图多模态能力，会话改为文件夹分类存储。

> ⚠️ 重要：本项目本地文件/命令执行功能**默认关闭**，需要用户手动开启。
> 模型提示词仅作为辅助，安全防护依靠代码硬校验，切勿将重要私人目录直接作为工作目录。

## ✨ v5.0 核心功能
- 🔌 **多模型API兼容**：支持任意OpenAI兼容接口，自由切换模型、填写自定义Base‑URL与API‑Key
- 🌐 **附属联网搜索API**：可接入搜索能力，让AI获取实时网络信息
- 🌍 **多语言UI界面**
- 🧹 **挡位式文本过滤**：符号过滤、标记格式化，支持自定义过滤挡位
- 📝 **代码块UI组件**：AI输出代码自动渲染独立区块；支持一键复制、HTML预览、全屏查看，适配亮/暗色主题
- 🛡️ **本地办公Agent沙箱（重点）**
  - 用户自定义选择本地工作目录，**代码层强制锁死路径**
  - 拦截`../`路径逃逸、绝对路径、符号链接、跨盘符访问
  - 文件读写、Shell命令默认关闭；命令白名单，未知命令弹窗申请权限（允许一次 / 永久允许 / 拒绝）
  - 全部IO操作限定在选定沙箱目录内，提示词无法绕过限制
- 👁️ **AI眼睛｜视觉截图能力**
  - Windows 使用原生GDI截图，**无需第三方图像依赖**；Linux/macOS调用系统截图工具
  - 支持全屏截图、导入本地图片，Base64提交给多模态模型
  - 截图自动保存至会话内`screenshots`文件夹，受沙箱管控
  - 需要选择支持视觉的模型（DeepSeek‑Flash、豆包视觉、Qwen‑VL等）
- 📂 **会话文件夹存储重构**
  - 会话ID格式：`[年月日‑时分]_[24位英数混合随机数]`
  - 每个会话独立文件夹，自动分类：chat、txt、json、py、java、html、screenshots
  - 向下兼容旧版本单txt聊天记录，平滑升级
- 📖 **内置帮助教程**：帮助窗口新增「本地办公」「AI眼睛」教程页，附带FAQ，中英双语

## ⚠️ 安全警告
1. 文件读写、Shell命令工具出厂默认关闭，**必须用户手动在设置面板开启**。
2. 建议使用独立文件夹/磁盘分区作为Agent沙箱，**不要把个人重要资料放入工作目录**。
3. 部署在云电脑环境时，请勿存放敏感隐私文件，仅用于AI任务运行。
4. 不要完全信任大模型输出的路径指令，防护逻辑依靠代码校验，而非模型提示词。
